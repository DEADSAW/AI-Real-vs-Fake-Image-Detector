🌍 Overview

The AI Real vs Fake Image Detector is an advanced deep-learning web app that identifies whether an uploaded image is authentic (real) or AI-generated (fake).
It uses a fine-tuned EfficientNet-B0 model built with PyTorch, presented through a dynamic Streamlit interface.

The model analyzes facial symmetry, pixel texture, and generative inconsistencies often found in AI-created visuals.
The app also features bilingual voice output (English + Hindi), feedback logging, and animated UI for a highly interactive user experience.

⚙️ Tech Stack
Component	Technology Used
Frontend	Streamlit, HTML/CSS Animations
Backend	Python (PyTorch, Torchvision, NumPy, OpenCV)
Model	EfficientNet-B0 (fine-tuned)
Voice	gTTS (Google Text-to-Speech)
Deployment	Streamlit Cloud / GitHub
🚀 Features

✅ Upload multiple images and detect if they are real or AI-generated
✅ Displays confidence score and bilingual voice output (auto for first image)
✅ Allows feedback (mark prediction as ✅ Correct / ❌ Wrong) — logged to CSV
✅ Dynamic UI with animated background, hover effects, and progress loader
✅ Automatically saves user feedback for iterative model improvement
✅ Works seamlessly both locally and online (Streamlit Cloud)

🧠 Model Details

The system uses transfer learning on EfficientNet-B0, trained on:

136,800 images for training

31,200 images for validation

Best validation accuracy: 97.9%
Training involved real human images and synthetic faces generated by advanced AI models (e.g., StyleGAN, Stable Diffusion).

🧾 Installation & Usage

1️⃣ Clone the repo

git clone https://github.com/yourusername/AI-Real-Fake-Detector.git
cd AI-Real-Fake-Detector

2️⃣ Install dependencies

pip install -r requirements.txt



3️⃣ Run the app

streamlit run app_final_voice_ui_finalpolish.py



4️⃣ Open the link shown in your terminal and upload images 🎯

☁️ Deploy on Streamlit Cloud

Push the repo to GitHub (public).

Go to https://share.streamlit.io
.

Click New App → select your repo → file path:

app_final_voice_ui_finalpolish.py


Click Deploy and enjoy your hosted version!

Your public link will look like:
👉 https://ai-real-fake-detector-yourusername.streamlit.app
